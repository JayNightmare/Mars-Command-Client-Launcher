# Roadmap

- Set the default Minecraft memory allocation to 6 GB.
- Preserve player data, mod configuration, and shader data across updates; provide a setting to include or exclude this persistent data during updates.
- Add the Mars server to the Minecraft server list.
- Add settings and quick actions to close launchers when Minecraft opens, report a bug, open the installation folder, and visit the GitHub repository and project website; include accessibility settings.
- Add a Fund This Project button. Future supporter benefits may include launcher customization and a special role on the Minecraft server and Discord.
- Add installation repair when the installed setup build differs from the current release. Check GitHub releases and parse the version from asset names such as `setup-[X.X.X].exe` and `setup-[X.X.X].deb`.
- Add Mission Control configuration and a Crew channel.
- Linux support: ship Linux installers and implement Linux-compatible Minecraft profile setup and launcher opening. These flows are currently Windows-only.
